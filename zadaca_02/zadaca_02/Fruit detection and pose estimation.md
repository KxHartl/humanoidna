The joint task is for students to divide among themselves 6 different fruit classes (3D printed) and perform annotation (INSTANCE SEGMENTATION) according to the lecture instructions and the dataset merging guidelines (see the additional PDF “Exercises”; pay attention to the last slides – “Dataset merging”).
First, create a shared .csv file with consistent class names (red apple, green apple, lemon, banana, avocado, walnut, pear). All students must upload this file to Roboflow to ensure consistent class labeling for CNN training.
After each student independently annotates their own training set (without augmentations), all datasets must be merged into a single dataset. This merged dataset is then uploaded again to Roboflow, where augmentations are applied and the final dataset is used for training.
