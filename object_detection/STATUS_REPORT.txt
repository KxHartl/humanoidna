CILJ ZADACE 3:
  Kompletan pipeline za Point Cloud obradu i 3D lokalizaciju objekta u sceni.

SPECIFIČNI ZAHTJEVI:

  A) SNIMANJE SCENE
     ✓ Snimiti minimalno 3 point clouda iste scene
     ✓ Različite pozicije kamere/robota
     ✓ Scena sadrži 7 tipova voća (po jedan od svake klase)
     ✓ Eksport u .pcd ili .ply format

  B) OBRADA POINT CLOUD-a (PCL Pipeline)
     Obavezni koraci:
     ✓ PassThrough Filtering - uklanjanje točaka van ROI-a
     ✓ Statistical Outlier Removal - uklanjanje anomalnih točaka
     ✓ VoxelGrid Downsampling - smanjenje broja točaka
     ✓ ICP Registration - usklađivanje cloud-a
     ✓ Point Cloud Stitching/Fusion - spajanje u jedan cloud
     ✓ Euclidean Clustering - segmentacija objekata
     ✓ RANSAC Plane Segmentation - detekcija planarnih površina
     
     OUTPUT: Jedan konačni registrirani point cloud scene

  C) DETEKCIJA I LOKALIZACIJA OBJEKTA
     Za zadani objekt (student ima definirani tip voća):
     ✓ Segmentacija objekta iz scene
     ✓ Pronalaženje centra masa (3D centroid)
     ✓ 3D lokalizacija u koordinatnom sustavu kamere
     ✓ Transformacija u koordinatni sustav baze robota

1. capture_point_clouds.py (~9.7 KB)
   ├─ Modul za snimanje point cloudova
   ├─ Klasa: PointCloudCapture
   ├─ Metode:
   │  • capture_from_realsense() - snimanje s Intel RealSense
   │  • capture_from_synthetic() - sintetički test clouds
   │  • capture_multiple_positions() - snimanje iz 3+ pozicija
   │  • save_pointcloud() - sprema u .pcd/.ply format
   └─ Testiran: DA (sa sintetičkim podacima)

2. pcl_processing.py (~16.3 KB)
   ├─ Kompletan PCL pipeline
   ├─ Klasa: PointCloudProcessor
   ├─ Metode implementirane:
   │  • passthrough_filter() - filtriranje po osi
   │  • statistical_outlier_removal() - SOR filter
   │  • voxel_grid_downsampling() - downsampling
   │  • estimate_normals() - procjena normala
   │  • icp_registration() - ICP registracija
   │  • register_and_merge_clouds() - spajanje cloudova
   │  • euclidean_clustering() - clustering
   │  • extract_clusters() - ekstraktovanje clustera
   │  • ransac_plane_segmentation() - RANSAC
   │  • process_point_cloud() - kompletan pipeline
   └─ Testiran: DA

3. object_detection_3d.py (~16.1 KB)
   ├─ Detekcija i lokalizacija objekta
   ├─ Klasa: ObjectDetectionAndLocalization
   ├─ Metode:
   │  • segment_by_color() - HSV boja segmentacija
   │  • segment_by_size() - filtriranje po veličini
   │  • segment_by_shape() - segmentacija po obliku
   │  • find_centroid() - pronalaženje centra masa
   │  • find_bounding_box() - bounding box
   │  • compute_principal_axes() - PCA analiza
   │  • localize_in_camera_frame() - 3D u kamerom sustavu
   │  • transform_to_robot_frame() - transformacija u robot sustav
   │  • detect_and_localize_object() - kompletan pipeline
   │  • Helper metode za transformacije (rotation matrices, itd.)
   └─ Testiran: DA

4. run_full_pipeline.py (~9.6 KB)
   ├─ Integracija svih modula
   ├─ Klasa: TaskaPipeline
   ├─ Koraci:
   │  1. step1_capture_point_clouds() - snimanje
   │  2. step2_process_point_clouds() - obrada svakog clouda
   │  3. step3_register_and_merge() - registracija i spajanje
   │  4. step4_cluster_objects() - clustering
   │  5. step5_detect_target_object() - detekcija objekta
   ├─ Primjeri korištenja
   └─ Testiran: DA (sa sintetičkim podacima)

⚠️  PYTHON VERZIJA:
    • Testirano sa Python 3.9+
    • Preporučena 3.10 ili 3.11

⚠️  GPU SUPPORT:
    • YOLO training/inference: CUDA 12.1 (za najnovije torch verzije)
    • Point cloud obrada: CPU je OK, ali GPU će biti brži

⚠️  MEMORIJA:
    • Point cloudovi sa 100k+ točaka trebaju ~500 MB RAM-a
    • ICP registracija je memorijski intenzivna

⚠️  KOORDINATNI SUSTAVI:
    • Kamera: Z-forward, Y-down (tipično za RGB-D kamere)
    • Robot: Varira ovisno o konfiguraciji - DEFINIRATI!
