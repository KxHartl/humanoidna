1. ANALIZA VJEZBE TRAJEKTORIJA
═══════════════════════════════════════════════════════════════════════════════

CILJ VJEZBE:
  Naučiti geneiriranje i slanje trajektorija za UR robota u zglobnom i task
  prostoru.

ŠTA JE KREIRANO U VJEZBI:

  Zadatak 1: Polinom prvog reda
    ✓ Jednostavna linearna interpolacija
    ✓ Bez razmatranja ograničenja

  Zadatak 2: Polinom 5. reda (Quintic)
    ✓ Glatke trajektorije s kontinuiranom brzinom i akceleracijom
    ✓ Učitava početnu i konačnu konfiguraciju
    ✓ Primjenjuje ograničenja (brzina, akceleracija, omega)
    ✓ Diskretizacija: 1000 točaka
    ✓ Output: Grafovi i datoteke s trajektorijama

  Zadatak 3: Task Space trajektorije
    ✓ Trajektorije definirane u task space-u (x, y, z, orijentacija)
    ✓ SLERP za interpolaciju orijentacije
    ✓ Konverzija između task i joint space-a
    ✓ Primjer 3D putanje TCP-a

  Zadatak 4: (Specijalizirana obrada - nije dostupna)
    - Task space transformacije u detaljima

  Zadatak 5: Slanje trajektorija robotu
    ✓ TCP/IP komunikacija s UR robotom
    ✓ Čitanje .txt datoteka s trajektorijama (URScript format)
    ✓ Real-time slanje servoj naredbi
    ✓ Simulacija u PolyScope-u

KEY OUTPUTS VJEZBE:
  • trajectory.txt - Trajektorija u zglobnom prostoru
  • trajectory_fifth_order.txt - Quintic polinom verzija
  • trajectory_task_space.txt - Trajektorija u task space-u
  • Vizualizacijske slike (pozicija, brzina, akceleracija)

KLJUČNE TEHNIKE:
  • Quintic (5. red) interpolacija
  • SLERP (Spherical Linear Interpolation) za rotacije
  • Procjena minimalnog vremena trajanja
  • Validacija ograničenja robota (v_max, a_max, omega_max)

2. PICK AND PLACE ZADATAK - NOVI ZAHTJEVI
═══════════════════════════════════════════════════════════════════════════════

CILJ ZADATKA:
  Autonomna hvatanja i odlaganja objekta s primjenom svih prethodnih znanja
  i tehnike.

5 OBAVEZNIH TOČAKA TRAJEKTORIJE:
──────────────────────────────────

  1. HOME
     ├─ Početna sigurna pozicija
     ├─ Joint konfiguracija [q1, q2, q3, q4, q5, q6]
     └─ Definirana u zglobnom (joint) prostoru

  2. APPROACH
     ├─ Iznad objekta (100mm offset po Z od PICK)
     ├─ Task space (x, y, z+0.1, rx, ry, rz)
     ├─ Sigurna pozicija prije hvatanja
     └─ Izračunava se automatski

  3. PICK
     ├─ Točka hvatanja objekta
     ├─ Iz Point Cloud obrade (ZADAĆA 3!)
     ├─ Task space koordinate u robot sustavu
     └─ Kalibrirana iz 3D lokalizacije

  4. APPROACH_PLACE
     ├─ Iznad mjesta odlaganja (100mm offset po Z od PLACE)
     ├─ Task space (x, y, z+0.1, rx, ry, rz)
     ├─ Sigurna pozicija prije odlaganja
     └─ Izračunava se automatski

  5. PLACE
     ├─ Točka odlaganja objekta
     ├─ Fiksna ili definiram po zadatku
     ├─ Task space koordinate
     └─ Poznata unaprijed

DEFINICIJA TRAJEKTORIJE:
────────────────────────

  Format:                    Task space (6D vektor)
  Kretnje između točaka:    Direktne (bez blend-a radijusa)
  Diskretizacija:          Fina (min 100+ točaka po segmentu)
  Robot kontrola:          Low-level regulacija + praćenje
  Interpolacija:           Quintic (5. red polinom)
  Glatkoća:                Kontinuirana brzina i akceleracija

OGRANIČENJA KOJA TREBAJU BITI POŠTOVANA:
──────────────────────────────────────────

  • v_max = 0.5 m/s (translacijska brzina)
  • a_max = 1.0 m/s² (translacijska akceleracija)
  • omega_max = 1.0 rad/s (kutna brzina)
  • q_dot_max = 360°/s (brzina zglobova)
  • q_ddot_max = 360-720°/s² (akceleracija zglobova)
  • Workspace ograničenja (x, y, z ranges)
  • Izbjegavanje singulariteta

OFFSET DEFINICIJA:
───────────────────

  APPROACH = PICK + [0, 0, 0.1]        # 100mm iznad objekta
  APPROACH_PLACE = PLACE + [0, 0, 0.1] # 100mm iznad mjesta

IMPLEMENTACIJSKA STRUKTURA:
─────────────────────────────

  7 SEGMENATA TRAJEKTORIJE (bez blendinga):
  
  1. HOME → APPROACH
     └─ Primjeri gorivo u položaj prije hvatanja
  
  2. APPROACH → PICK
     └─ Desno spuštanja prema objektu
  
  3. PICK (pause)
     └─ Vrijeme za zahvaćanje (gripper zatvoren)
  
  4. PICK → APPROACH_PLACE
     └─ Brzo dizanja iz PICK pozicije
  
  5. APPROACH_PLACE → PLACE
     └─ Desno spuštanja prema mjestu odlaganja
  
  6. PLACE (pause)
     └─ Vrijeme za otpuštanje (gripper otvoren)
  
  7. PLACE → HOME
     └─ Povratak u početnu poziciju
